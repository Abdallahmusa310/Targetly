# 🎯 Targetly

**Targetly** is a sales and client management application designed to help sales representatives, account managers, and business owners track targets, manage clients, monitor performance, and generate detailed reports — all in one place.

### 🚀 Key Features

#### 🔐 Authentication

* Secure Email & Password Authentication
* Sign In / Sign Up
* Password Reset via Email
* First-Time Welcome Experience
* Multi-user data isolation using Firebase UID

#### 🎯 Target Management

* Create sales targets with custom date ranges
* Monitor achieved vs remaining target
* Animated progress tracking
* Commission calculation
* Days remaining indicator
* Target reset functionality

#### 👥 Client Management

* Add, edit, and delete clients
* Store client information (Name, Phone, ID, Fees)
* Automatic subscription status detection
* Client notes and comments system
* Search clients instantly
* Filter clients by subscription status
* Direct phone calling integration
* Swipe actions for quick editing and deletion

#### 📊 Reports & Analytics

* Generate reports for any date range
* Sales summary dashboard
* Target progress tracking
* Interactive sales charts
* Period-based client analysis
* Commission reporting

#### 🏠 Dashboard

* Personalized greeting
* Live target tracking
* Commission overview
* Client statistics
* Daily performance summary
* Recent activity timeline
* Quick action shortcuts

#### 👤 Profile & Settings

* Edit username and job title
* Dark / Light Mode
* Arabic & English language support
* Account information
* Data management tools
* Logout functionality

#### 🌍 Localization

* Arabic & English support
* Full RTL compatibility
* Dynamic language switching
* Localized numbers and content

#### ✨ User Experience

* Modern responsive design
* Smooth animations
* Animated splash screen
* Animated welcome screen
* Interactive dialogs
* Elegant navigation experience

Targetly helps users stay focused on their goals by providing a simple yet powerful platform for tracking sales performance, managing clients, and monitoring business growth efficiently.
